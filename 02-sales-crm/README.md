# 02-sales-crm

Ne işe yarar: Lead'den kazanılan/kaybedilen fırsata kadar satış hunisinin tek kaynağı.
Source of Truth: Müşteri adayı durumu (STATUS) için tek kaynak burasıdır.
Buraya ne konur: pipeline (aktif fırsatlar; görüşme/WhatsApp/teklif notları dahil), won, lost, referrals, sales-kpi.
Buraya ne konmaz: Kazanılan müşterinin operasyonel çalışması (bkz. 03-clients). won klasörü sadece kapanış referansı tutar.
Günlük kullanım: pipeline/ STATUS alanına göre güncellenir; Command Center SALES bloğu buradan beslenir.
