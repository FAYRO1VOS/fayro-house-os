# 09-reporting

Ne işe yarar: Geçmişe dönük performans ve KPI'ların dashboard/rapor haline getirildiği alan.
Source of Truth: Bu bölüm veri üretmez, özetler. Ham veri kaynakları: sales-crm, finance, clients, operations.
Buraya ne konur: Haftalık/aylık raporlar, dashboard özetleri.
Buraya ne konmaz: Ham/birincil veri (kopyalanmaz, sadece referans alınır).
Günlük kullanım: Haftalık/aylık review'larda kullanılır; günlük özet için Command Center yeterlidir.
