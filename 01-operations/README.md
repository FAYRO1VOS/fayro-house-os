# 01-operations

Ne işe yarar: Şirketin günlük ve haftalık işleyişi — görevler, teslimler, kalite kontrol, ekip.
Source of Truth: Tüm görevler için tek kaynak burasıdır (Operations = Task System).
Buraya ne konur: Görev kayıtları, teslim takibi, günlük/haftalık rutinler, ekip bilgisi.
Buraya ne konmaz: Müşteriye özel stratejik içerik (bkz. 03-clients), finansal kayıt (bkz. 05-finance).
Günlük kullanım: Sabah tasks/ ve daily-os/daily-start kontrol edilir; akşam daily-os/daily-close ile kapatılır.
