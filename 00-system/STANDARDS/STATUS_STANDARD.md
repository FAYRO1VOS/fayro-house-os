# Status Standardı

Görev: BACKLOG -> READY -> IN_PROGRESS -> REVIEW -> BLOCKED -> DONE -> ARCHIVED
Satış: NEW -> CONTACTED -> QUALIFIED -> MEETING -> PROPOSAL -> NEGOTIATION -> WON -> LOST
Müşteri: ONBOARDING -> ACTIVE -> AT_RISK -> PAUSED -> COMPLETED -> ARCHIVED
  ACTIVE tanımı: sadece ödeme yapan değil, üretim süreci fiilen devam eden müşteri (Legacy Spec madde 4.17).
İçerik: IDEA -> BRIEF -> SCHEDULED -> SHOOT -> EDITING -> CLIENT_REVIEW -> REVISION -> APPROVED -> PUBLISHED -> REPORTED

Kural: Her modül kendi durum ismini icat etmez, yukarıdaki dört döngüden birini kullanır.
